WakeCanvas

No installation is required. Keep this entire folder together.

Show the presentation

  1. Double-click start-wakecanvas.cmd.
  2. If asked, choose a six-digit management code.
  3. Your prepared display opens in the browser.

Use stop-wakecanvas.cmd when finished. Use open-management.cmd to select a display or manage content.

Permanent kiosk

start-kiosk-mode.cmd opens fullscreen. An operator can later use the clearly separated admin-tools folder to launch it after Windows sign-in.

Your content

Everything created after first start is kept in the data folder. Back up that folder to preserve workshops and media.
