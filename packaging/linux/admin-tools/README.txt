WakeCanvas Admin Tools
======================

These scripts are for installation setup, automatic-start configuration,
advanced launch options, and recovery. Normal users should return to the parent
WakeCanvas folder and use:

  ./start-wakecanvas.sh
  ./stop-wakecanvas.sh
  ./start-kiosk-mode.sh
  ./open-management.sh

Changing initialization or service settings can interrupt a running installation.
The normal ../stop-wakecanvas.sh command is the supported way to stop every
process owned by this installation before moving or deleting its folder.
