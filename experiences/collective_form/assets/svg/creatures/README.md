# Creature template sources

- `pigeon.svg` was downloaded from SVG Repo as “Pigeon Bird Peace Dove”. Before
  release, retain the individual source-page URL and confirm its displayed license.
- `rabbit.svg` is from
  <https://www.svgrepo.com/svg/307537/rabbit-hare-horny-cute> and is marked CC0.

The files are bundled into the browser-ready renderer at build time. They do not
introduce a network or production runtime dependency.

`pigeon-rig.svg` and `rabbit-rig.svg` are original WakeCanvas MVP assets built
from named geometric body-part paths. They are the runtime animation templates;
the downloaded files remain source references only.
